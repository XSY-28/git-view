# 第四批：分支与提交比较

目标：比较两个 Git 端点，查看各自独有的提交、共同祖先与文件差异。承接二、三批；文件历史、搜索、stash/reflog 和任务前后基线继续留在后续批次。

## 约束与完成标准

- [x] 端点可选 HEAD、本机引用或完整/短提交 ID；先解析为固定 OID，不接受任意 revision 表达式、路径或命令。
- [x] 两端树 A → B 与唯一共同祖先 → B 是独立内容比较；显示实际端点和方向，支持交换 A/B。
- [x] 同时给出 A/B 各自独有的提交及固定端点分页；分支移动不混入下一页。
- [x] 无共同祖先、多个 merge-base、浅历史、缺失对象和超限结果不伪造空列表或确定结论。
- [x] 复用只读适配器、核心身份门控、文件列表与差异视图；新读取保留语言切换、键盘和窄窗口行为。
- [x] 真实仓库覆盖分叉、merge、改名、首次/相同提交、浅历史、多个 merge-base、分支移动和只读指纹；迟到成功/错误、旧分页和切仓库均不污染当前结果。
- [x] 类型检查、相应测试、Web/桌面构建与安装版原生窗口通过；只记录实际验证范围。

## 架构

独立 comparison 契约；Git comparison reader 只接受受限端点并用 immutable OID 执行固定只读命令。core 保存有上限、绑定会话观测的比较 ID，详情与分页均使用该结果中的端点。React 比较视图有自己的请求身份与选择状态，复用现有 DiffView、ChangeList 和 ReadFeedback。分支比较不会触发写操作或联网。

## 交付

本批比较能力在独立功能分支实现。它只读取本机 Git 对象，不包含远程同步或任务前后基线。
