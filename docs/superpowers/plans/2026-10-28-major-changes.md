# 重大变更阅读与历史日期：实施及验收

用户已批准聊天方案，并授权实现、导入 DSH 文章、更新正式桌面应用及实际界面验收。

目标：在版本比较右侧增加“重大变更”，离线阅读每仓库一篇 Markdown（表格、引用、Mermaid、图片）；历史行直接显示作者日期。沿用当前暖色界面，不绑定文章章节与提交，不改变历史排序。

## 实施
- [x] contracts/article.ts 定义持久文章与导入/选择协议；local/articles.ts 负责限量读取、图片打包、原子替换、仓库隔离。Markdown 只读导入，引用图片限定在所选资料目录内，不执行 HTML。
- [x] 在本机文件选择器提供 Markdown/文件夹选择；多 Markdown 目录由用户选择主文。导入与读取走现有鉴权服务，不扩大传输大小上限。
- [x] web/features/articles 负责目录、连续正文、图表、放大、导入错误和阅读位置；复用 App 导航与仓库会话。Markdown 标准标题生成目录，不猜测加粗文本。
- [x] HistoryGraph 第二行显示 YYYY-MM-DD，窄窗口优先保留日期；悬停注明作者日期、完整时间和时区。
- [x] 从“设计演化史学习 Skill”取得完整 DSH 文章，仅将转折标题规范为 Markdown 标题，保存来源与版本边界。
- [x] 检查、安装测试、浏览器端到端验证；退出 Git View，pnpm update:desktop；固定安装路径导入并检查文章、Mermaid 和日期，重启确认持久化。

## 验收与验证方法
存储测试使用临时目录：重启读取保留 Markdown/相对图片；不同仓库隔离；无效替换保留旧文章；越界、符号链接、非普通文件、超限输入拒绝或有明确警告。测试 finally/afterEach 清理。

浏览器真实服务测试：导入 DSH 型图文、目录跳转、Mermaid 成图且可放大；来源移除后重载可读；切换视图/仓库保持正确文章及位置；日期在长标题和窄屏可见；错误图不阻断正文。

全量 pnpm check，相关 e2e 和 pnpm test:install-desktop。原生 GUI 只用 ~/Applications/Git View.app，不复制测试 app；安装注册检查不当作搜索界面验收。
