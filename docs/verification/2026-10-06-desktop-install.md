# macOS 单路径安装与恢复验证

日期：2026-10-06。

`pnpm install:desktop` 将已构建的应用安装到固定的 `~/Applications/Git View.app`。更新前校验应用身份、版本、构建清单与资源哈希；旧安装保存为 ZIP，替换成功后注销并移除本次构建副本，减少同名应用入口。运行中的应用会阻止安装，不会被强行退出。`--dry-run` 仅检查，不写入或注册应用。

## 自动化验证

本地运行 `pnpm test:install-desktop`：12 项通过，0 项失败。测试在临时目录执行真实文件复制、ZIP 归档、解包恢复和逐文件指纹比较，覆盖：

- dry-run 不修改文件或注册状态。
- 首次安装、更新与旧版 ZIP 保存。
- 运行中拒绝、资源损坏拒绝。
- 备份失败保持旧安装，注册失败回滚。
- 注销失败保留构建并报告恢复路径。
- 并发生成或修改构建时保留该副本。

测试使用系统 `plutil`、`ditto`、`unzip`；应用注册和进程查询使用替身。它们验证文件事务与恢复路径，不等同于安装脚本的真实系统端到端验收。GitHub CI 在两种 macOS runner 上运行这组测试；其他平台跳过。

## 手动验收方法

构建后退出 Git View，先执行 `pnpm install:desktop --dry-run`，再执行 `pnpm install:desktop`。核对固定安装路径、备份 ZIP、构建副本清理及应用启动；重新输入 Spotlight 搜索词，确认只显示一个 Git View。系统文件索引或应用注册表的计数不能代替搜索界面的实际结果。

安装脚本本身不清空系统搜索索引，也不重启搜索服务。历史上同一安装曾在搜索面板中重复显示；该类系统缓存症状需要另行复测，不能从安装成功推断搜索界面已刷新。
