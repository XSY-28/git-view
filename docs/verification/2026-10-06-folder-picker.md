# 2026-10-06 · 原生文件夹选择验收

本轮将“打开仓库”改为 macOS 原生文件夹选择流程，并保留最近仓库和手动路径入口。**自动化检查及本机真实窗口的核心流程已通过；这不代表原 MVP 的全部验收已经完成。**

## 功能与实现范围

- 点击页面顶部“打开仓库…”直接弹出系统文件夹选择窗口，支持选择仓库根目录或其中的子目录。
- 选择文件夹后，仍通过原有 `open` 接口解析、验证 Git 仓库；验证成功才切换会话。选择器本身不创建仓库会话，也不提供文件上传或任意文件系统列表接口。
- “最近仓库”使用独立入口；“手动输入路径”收在可展开区域，供备用使用。
- 选择和验证期间显示忙碌状态，禁止重复打开。该流程使用独立的请求门禁，系统窗口关闭引起的焦点恢复不会取消正在进行的仓库验证。
- 取消保留当前仓库；非仓库目录或选择器失败显示明确错误及备用入口。页面关闭或主动取消会中止对应请求，迟到结果不能切换仓库。

macOS 选择器由 Swift AppKit helper 实现，使用 `NSOpenPanel`。从源码执行构建需要 Xcode Command Line Tools 或完整 Xcode；运行已构建产物不需要 Swift 编译器。Windows/Linux 保留手动路径入口，本轮未在这些平台上实际验证。

## 本机真实窗口验收

本轮使用 CUA 操作真实网页和 macOS 系统窗口，确认以下行为：

| 操作 | 实际结果 |
| --- | --- |
| 点击网页“打开仓库…” | 出现带 Finder 侧边栏的原生 `NSOpenPanel` 文件夹选择窗口 |
| 选择本项目的 `apps/web` 子目录 | 解析到项目根目录，页面加载 `main`，正确显示“尚无首次提交” |

原生窗口截图含本机用户名，未随仓库上传。会话保留、错误处理和子目录解析结论来自上述交互过程。
