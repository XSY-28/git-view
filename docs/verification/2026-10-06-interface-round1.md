# 界面优化第一轮：布局与入口

日期：2026-10-06。对应 [三轮界面优化计划](../superpowers/plans/2026-10-06-interface-refinement.md) 的第一轮；本记录不代表产品 2B 或 Git 写操作阶段完成。

## 本轮变更

- 顶部仓库名称是统一切换入口：打开仓库、最近仓库、多个 worktree、完整路径和复制、手动路径集中在一个弹层。当前仓库不在最近列表重复出现；已有 worktree 也不重复列入最近仓库。
- 侧栏只管理历史范围。当前分支在顶部和分支列表中明确标记，筛选其他引用不会被显示成已经切换分支。
- HEAD 已加载时显示“定位 HEAD”；不在当前加载范围时显示“查看 HEAD 历史”，点击后的范围变化能提前看见。
- 压缩工具栏，移除重复的品牌、路径、只读状态与范围重置入口。
- 提交摘要保留标题、作者、日期和复制 ID；比较语义默认可见。完整 ID、父提交、精确时间及完整基准按需展开；文件列表可收起，长列表独立滚动。

仓库切换器、提交摘要各自管理展示与样式，历史范围名称集中定义；继续复用现有控制器、请求身份检查和只读核心，无新增 Git 命令或宿主业务分支。

## 原生桌面核对

将本轮构建的 `Git View.app` 复制至独立临时目录，以隔离的 `GIT_VIEW_HOME` 启动，读取含中文和空格路径的真实演示仓库。通过原生窗口操作确认：

- 紧凑工具栏、历史范围侧栏与仓库切换器实际呈现；菜单内完整路径可见。
- “打开仓库…”拉起 macOS 原生目录窗口；取消后仍显示原仓库和原文件差异。
- Esc 关闭切换器，焦点返回仓库名称按钮。
- 首次提交默认显示“相对空树（首次提交）”；展开可查看完整提交 ID、时间和无父提交信息，收起后恢复紧凑摘要。
- 选择 `topic` 后历史范围变为 `topic`，顶部仍显示当前分支 `main`；所选提交的真实差异行可见。
- 正常退出临时桌面副本，启动进程返回退出码 0。
