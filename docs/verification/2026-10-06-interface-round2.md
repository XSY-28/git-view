# 界面优化第二轮：差异呈现与文件导航

日期：2026-10-06。对应 [三轮界面优化计划](../superpowers/plans/2026-10-06-interface-refinement.md) 的第二轮；第三轮刷新和反馈调整仍待施工。

## 变更与边界

- 默认代码区省略 `diff --git`、`index`、`---`、`+++` 等重复补丁头，保留 hunk、真实行号、增删内容和文件末尾未换行标记。重命名、复制与文件模式变化单独显示；二进制或截断补丁仍保留已确认的新旧路径。
- 原始补丁默认收起，可展开和复制，字符串保持原样。不完整结果明确标注“已获取部分”，不冒充完整补丁。
- 差异模式使用“单列／并排”，比较两侧明确标注 HEAD、暂存区、工作区、父提交或空树、所选提交；对象 ID 保留在基准栏。首次提交不伪称存在父提交。
- 未跟踪文本固定单列单行号，只显示适用的折行控件。看似补丁的文本仍原样显示；末尾换行不虚增一行，空文件明确显示。
- 当前改动与提交文件共用路径筛选和键盘导航。筛选匹配新旧路径，按 worktree 与视图分别记忆；匹配当前文件则保留，筛掉时取消请求并清空详情，清除筛选不会自动抢选。
- 上下方向键及 Home/End 跳过折叠分组和不可读取条目，焦点随目标行保持可见；窄窗口用方向键不会切走列表。提交文件筛选框位于文件滚动区域外，避免首行被遮挡。

`ChangeList` 收拢文件列表展示，筛选函数和方向键规则独立复用；`diff-presentation` 统一比较对象和补丁呈现。App 仍负责请求及选中状态，控制器按 worktree 保存视图记忆。Git 核心、读取契约和宿主传输未增加第二套业务逻辑。

## 原生桌面核对

将最终构建复制到独立临时目录，以隔离的 `GIT_VIEW_HOME` 打开中文/空格路径的真实演示仓库。实际原生窗口确认：

- HEAD→暂存区显示 V1→V2，暂存区→工作区显示 V2→V4；默认正文没有重复补丁头。
- 展开原始补丁可见完整已读取文本；复制操作返回“已复制补丁”。剪贴板字节一致性由浏览器测试单独核对。
- 未跟踪文件只有单列行号、内容和折行；没有差异模式按钮或空白比较列。
- 输入“说明”后排除原选中的未跟踪文件，详情清空且焦点仍在筛选框。
- 从筛选框 Tab 进入文件列表，Down 跨暂存/未暂存分组，焦点和真实比较同步；折叠未暂存组后 End 留在可见暂存文件。
- 提交视图提供独立文件筛选，首次提交明确显示“空树 → 所选提交”，真实新增内容可见。
- 正常退出临时验收副本，进程返回退出码 0。
