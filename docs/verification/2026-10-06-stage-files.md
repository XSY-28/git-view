# 第一批：按文件暂存与取消暂存

日期：2026-10-06。用户授权完成本批后做一次本地提交。本批实现独立写入基础及整文件暂存/取消暂存；普通提交、分支写入、merge/rebase 和推送不在本批范围。

## 功能与架构

- 文件列表新增明确的操作勾选，保持点击文件查看差异的原有行为。选定文件后复用现有差异视图预览，再确认执行；没有隐式全量暂存。
- contracts 分开基础模型、只读协议与操作协议。写请求只能选择 `stage-files` / `unstage-files`；执行只提交一次性预览 ID 和操作 ID，不能追加路径或命令。
- `packages/operations` 负责预览、队列、持久回执与恢复；`packages/git-write` 负责受限 Git plumbing、冻结内容、索引锁和结果证据。页面不拼 Git 命令，只读 runner 未增加写命令。
- 预览默认 60 秒有效，绑定会话、工作区、HEAD、index、配置与所选文件。执行使用独立临时 index，重验前提后以 `index.lock` 原子安装；工作文件从不被写入。
- 操作 ID、待核实标记和安装证据在写入前持久化。刷新、重启或执行响应丢失时查回执；不能证明结果时保留未知状态，不自动再次执行。已完成历史不参与待核实扫描。
- 写入期间暂停同工作区所有会话读取并失效旧请求，完成后刷新。HTTP 写入口仅授权页面可用；CLI bearer 和原有读入口拒绝写请求。桌面使用单独的 write 信封，普通 stdio 默认没有写能力。

## 明确边界

- macOS Apple silicon 是本批实机验收目标。Windows 明确拒绝写入，禁用协调器不创建写入存储，保留原有查看服务；平台契约测试验证此行为。POSIX 写入套件在 Windows 跳过，协议 schema 测试仍运行。Windows 和 macOS Intel 的实际运行、本次远程 CI 尚未验证。
- 首批支持常规 v2/v3 index，拒绝冲突、进行中的 Git 操作、稀疏/split index、特殊标志、submodule 与非 UTF-8 路径。
- 整文件暂存暂不实现 `text` / `eol` / `ident` / `working-tree-encoding` 或 autocrlf 转换。外部过滤器明确拒绝；不执行 `post-index-change` hook。取消暂存直接恢复 HEAD 中的 index 条目，不改工作文件。
- 上限为 200 个选定条目、单文件 64 MiB、选定内容合计 128 MiB、index 32 MiB。无法展示文本差异时明确提示仍是整文件操作，不能伪装成空差异。
- 进程异常退出后的应用锁不自动删除。先核实原操作与进程状态，再按错误中给出的应用锁路径处理；不清除外部 Git 的锁。
- 本批更新 Windows 测试夹具的空配置路径，跳过不适用的 POSIX 原生选择器测试；这是本地代码修正，不能替代 Windows CI 通过的证据。
