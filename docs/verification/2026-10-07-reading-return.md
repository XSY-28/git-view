# 历史返回与窗口刷新

日期：2026-10-07；macOS Apple silicon。

## 行为

- 从提交搜索、文件历史或行来源打开提交后，显示“返回搜索结果”或“返回文件历史”。返回恢复已加载记录、选择、页面与列表滚动；文件历史恢复差异或比较前/后行来源，以及内容的两条滚动轴。有效结果复用原有读取身份，原来的按钮或结果行重新获得焦点。
- 结果与阅读位置由当前窗口的 worktree 保存，输入条件仍由原来的 worktree 导航状态保存。切换 worktree 不混用结果；新会话或刷新代次需要重读时，重新加载此前已加载的范围。关闭应用后不持久化调查结果。
- 中断的请求不会恢复为正在读取或有效结果。取消与错误状态在同一读取上下文内保留，回到页面不会隐式重试；明确重试或新的仓库更新仍可以恢复读取。
- 切回窗口先读取概览、引用和监听状态进行核对。确认没有变化时保留原有读取代次、分页、内容和展开状态。正在进行的概览/引用读取不被同查询的检查请求取消；检查失败、身份不匹配或监听不可用时走原来的完整刷新。
- 手动刷新、监听报告的新失效事件和必要的过期恢复继续完整读取。监听事件只表示观测失效，不能证明是哪项 Git 事实发生变化。排队的完整刷新不会被后来的焦点事件降级；取消、仓库切换和写入开始都会使检查请求失效。
- 比较的端点与共同祖先相同时，完整刷新保留详情展开状态；端点变化时重新建立详情。
