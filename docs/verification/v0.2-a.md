# V0.2 第一批（2A）施工与验收

日期：2026-10-06。当前交付为 macOS Apple silicon 上可运行的只读桌面预览版，包含导航、文本比较与自动刷新。第二批 2B 的任务基线、文件历史调查、LFS 与 MCP/DSH，以及第三阶段 Git 写操作尚未施工。

## 实现与架构

- `packages/contracts` 定义导航与筛选历史契约；`core` 负责会话、generation、queryKey/requestId 与结果门禁；`git-cli` 负责系统 Git 和读取一致性。Rust 不实现 Git 语义。
- `apps/local/src/service.ts` 共用打开、最近仓库和查询用例；HTTP 保留鉴权，桌面以固定入口 stdio 调用同一服务。`apps/web/src/state/transport.ts` 是两个实际宿主的传输切换点。
- 桌面原生目录选择、单实例和子进程监督属于 `apps/desktop`。EOF 先取消读取，有界等待后清理进程树；异常协议拒绝该代 pending，下一次查询可重启。
- 导航、diff 对齐、界面偏好和刷新队列分模块。每个 worktree 分别保存选择、筛选和滚动。Git 超时、输出、分页及预览预算集中于 `packages/git-cli/src/limits.ts`；宿主预算集中于 Rust `config.rs`；自动更新时序集中于 UI 的刷新配置与队列。
- 文件事件只失效旧观测。读取前后核对 Git/工作树状态，最多初读加两次重试；持续变化返回明确错误。UI 对短时刷新保留尾随请求，不吞掉唯一一次失效事件。

原生 GUI 通过 CUA 操作临时安装副本，实际观察到：

1. CLI `open` 打开中文/空格路径；显示 V1→V2 的已暂存比较和 V2→V3 的未暂存比较，并排模式左右行号对应。
2. 原生目录对话框取消后仍保留当前仓库和未暂存选择；选择另一个真实测试仓库后实际路径与内容改变。
3. 重复 CLI `open` 把现有窗口切回指定仓库，并恢复此前未暂存选择。收据仍只声明 `rendered:unverified`；这里的窗口观察单独构成渲染证据。
4. 从外部将测试文件改成 V4，未点击刷新，原生窗口自动显示 V2→V4。
5. 主动终止本次测试的 Node 查询子进程后，页面显示 `STALE_RESULT`；通过最近仓库重新打开后建立新 session、恢复正常读取，不把失败显示成干净状态。
6. 最终包不传仓库参数冷开窗口，自动恢复上次仓库，仍正确显示已暂存/未暂存两份比较；重启保留并排偏好。
7. 最终包在后台窗口首次点击未暂存文件时，立即选中并显示正确 V2→V4。已修复 focus 刷新插入提示造成行位移的问题；文件、历史、导航的后台状态均保持固定位置，过期与取消仍可见。
8. 正常退出后，按测试安装路径检查进程列表，无遗留原生宿主/Node 查询进程。独立 Rust 测试另覆盖读取中退出的 Git 后代。

一次性 RSS 样本：原生宿主约 119 MiB，Node 查询进程约 75 MiB。未合并 WebKit 系统进程，不能称为完整应用内存或稳定空闲基准；原生冷启动耗时未作受控采样。

## 复现与卸载范围

```sh
pnpm build
pnpm build:desktop
pnpm verify:installed --app "apps/desktop/src-tauri/target/release/bundle/macos/Git View.app"
```

双击上述 `.app`。安装副本不需 Node/Swift/Rust，仍需系统 Git。源码构建需要 Node 24.19.0、pnpm 11.7.0、Rust 工具链与 Xcode Command Line Tools。

退出窗口后可删除所复制的 `.app`。需要移除最近仓库时，仅删除明确的应用状态目录（默认 `~/.local/share/git-view`，或自己的 `GIT_VIEW_HOME`）；不删除仓库。项目内 `.tooling/`、Rust target/resources 和 `dist/` 是忽略的构建缓存。
